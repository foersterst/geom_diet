## Gradual evolution of larval dietary breadth and its correlated effects on body size diversification in geometrid moths

### Repository structure

- `bt/`: contains the scripts (`infile-3p.txt` and `infile-5p.txt`), input data (`bt/data`), and output files (`bt/output`) of the variable-rates model from BayesTraits 4.
- `data/geom_tree.nex` and `data/geom_traits.csv` are the main files (tree and trait data, respectively) used in the comparative analyses presented in the manuscript.
- `out/` contains output files (e.g., figures and tables) created during the analyses.
- `/scripts/data_analysis.R` is the main R script used to run all analyses in R, including post-processing of BayesTraits files.
